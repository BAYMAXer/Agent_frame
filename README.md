# Agent_frame

OSWorld GUI Agent 框架。

当前版本：**0.2.3**（[v0.2.3 Release](https://github.com/BAYMAXer/Agent_frame/releases/tag/v0.2.3)）。

源码直接位于仓库根目录，不同版本通过 Git 标签保存。本版本的发布源码不包含测试文件。

| [v0.2.3](https://github.com/BAYMAXer/Agent_frame/tree/v0.2.3) | osworld_agent_1010 当前版本，不含测试文件 |

在仓库根目录启动 Windows 可视化工作台：

~~~powershell
python launch.py
~~~

打开 http://127.0.0.1:8088 。启动器会自动识别当前目录，无需更改仓库目录名称。
