# 本地 Windows 依赖与运行说明

当前版本只在 Windows 本机执行任务。网页操作使用独立无痕 Chrome 和 CDP，桌面兼容流程使用本机窗口与输入接口。决策与定位模型通过 OpenAI 兼容 API 访问，服务可以在本机或远程。

## 安装依赖

准备 Python 3.12 和 Google Chrome，在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\osworld_agent_1010\requirements-dev.txt
.\.venv\Scripts\python.exe .\osworld_agent_1010\launch.py
```

打开 [工作台](http://127.0.0.1:8088)。Chrome 默认路径为 `C:\Program Files\Google\Chrome\Application\chrome.exe`。命令行可通过 `--chrome` 指定其他安装位置，`--browser-port` 指定空闲调试端口。

直接任务入口使用与工作台一致的参数：

```powershell
.\.venv\Scripts\python.exe .\osworld_agent_1010\launch.py --runner local --task "搜索 Attention Is All You Need，找到论文并下载 PDF"
```

默认启用 `browser_first`，规划完成后按顺序下发子任务。使用 `--execution-mode desktop` 切换本机桌面兼容流程。默认最多 20 步、单步 120 秒、精简 AX 最多 5000 字符、浏览器输入截图最长边 1280 像素。

## 依赖用途

| 依赖 | 用途 |
|---|---|
| openai、httpx、requests | 调用决策/定位模型与本机 CDP 服务 |
| playwright | 控制受管 Chrome 页面、获取 AX 和 viewport 截图 |
| Pillow | 处理浏览器与本机截图 |
| PyAutoGUI | 桌面兼容流程的鼠标、键盘与截图 |
| PyYAML | 动作、技能、模型预设和配置解析 |
| fastapi、uvicorn[standard] | 本机工作台 HTTP 与 WebSocket 服务 |
| pytest | 离线回归 |

上述直接依赖版本固定在 `requirements.txt`，测试入口使用 `requirements-dev.txt`。浏览器任务连接系统 Chrome，不需要下载 Playwright 自带的浏览器。完整模型输入输出和图片引用保存在本机 `local_runs` 中。

## 配置与验证

在工作台选择决策与定位模型名称、API 地址和协议；预设来自 `config/model_presets.yaml`。模型可以远程托管，执行始终留在当前 Windows 主机。API Key 可在界面填写或通过 `OSWORLD_LOCAL_MODEL_API_KEY`、`OSWORLD_LOCAL_GROUND_API_KEY` 配置；认证信息不保存到工作台配置草稿。

`OSWORLD_RUNNER_PYTHON` 可显式指定本机 Python 解释器。没有配置时，任务运行器使用启动工作台的 Python。`OSWORLD_LOCAL_RUNS_DIR` 可指定本机轨迹保存目录。变量名称保留兼容现有设置。

```powershell
.\.venv\Scripts\python.exe -m pytest .\osworld_agent_1010\tests -q
```

测试自动绑定当前版本目录。界面回归需要 Node.js 与 Node Playwright；配置方法和工作台详情见 [Windows 可视化工作台](Windows可视化工作台.md)。

`config.yaml` 是供集成代码使用的 Windows 配置示例，`Config.load` 可以读取。工作台和命令行通过表单和参数配置执行任务，不读取任务数据集或外部执行环境。
